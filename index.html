Sobre IMPULSO

IMPULSO es una plataforma web diseñada para conectar emprendedores con clientes, permitiendo publicar y descubrir productos o servicios de manera sencilla.

🎯 Objetivo

Validar la idea de un marketplace digital enfocado en emprendimientos locales, usando tecnologías web modernas.

🛠 Tecnologías usadas

  • HTML5 semántico
  • CSS moderno (Flexbox y Grid)
  • JavaScript vanilla
  • GitHub Pages (hosting)

📌 Estado del proyecto

Versión 1.0 – Frontend funcional (MVP). En futuras versiones se añadirá backend, autenticación y pagos.
